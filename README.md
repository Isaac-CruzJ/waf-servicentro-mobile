# W.A.F. AutoCare — Aplicación de gestión de servicios de lavado de vehículos

## Descripción del proyecto

W.A.F. AutoCare es una aplicación móvil diseñada para facilitar la gestión de los servicios y las reservas de un lavacar. La aplicación permitirá a los clientes consultar los tipos de lavado disponibles, registrar sus vehículos, reservar citas y consultar el estado de sus servicios.

Además, contará con herramientas para administrar el catálogo de servicios y las reservas, aplicar filtros personalizados, adjuntar fotografías de los vehículos y visualizar la ubicación del negocio mediante un mapa.

El proyecto busca mejorar la organización de las citas, facilitar la comunicación con los clientes y ofrecer una experiencia de uso sencilla y práctica.

## Objetivo general

Desarrollar una aplicación móvil que permita gestionar los servicios de lavado de vehículos y las reservas de los clientes mediante una interfaz intuitiva y funcionalidades que faciliten la administración del negocio.

## Funcionalidades principales

- Gestión de servicios y vehículos mediante operaciones CRUD.
- Registro, consulta, modificación y cancelación de reservas.
- Listado de reservas con filtros personalizados.
- Acceso a la cámara o galería para adjuntar fotografías de vehículos.
- Diálogos de confirmación para acciones importantes.
- Visualización de la ubicación del lavacar mediante un mapa.
